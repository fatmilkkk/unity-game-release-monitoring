# Журнал изменений

Формат: [семантическое версионирование](https://semver.org/lang/ru/) — MAJOR.MINOR.PATCH.

## [1.2.0] — выпуск и мониторинг (кейс-задача № 5)
### Добавлено
- Анонимная аналитика с согласием игрока: сессии, прохождение, воронка, причины и места гибели, предметы, FPS
- Сбор ошибок и исключений с дедупликацией (CrashReporter)
- Окно отзыва в игре (оценка, тип, текст, техническая информация) → GitHub Issues
- Шаблоны обращений GitHub (ошибка, отзыв)
- Удалённый конфиг: баланс (порог взрыва бочки, урон препятствий, нормативы звёзд), новости, сообщение об обновлении
- Окно «Что нового», карточка новостей и уведомление о новой версии в главном меню
- Инструменты релиза: сборка Windows / Android (APK, AAB) / WebGL, номер сборки, build_info.json, отчёты о сборке
- Панель анализа статистики в редакторе с рекомендациями и картой мест гибели
- GitHub Actions: тесты и сборка всех платформ по тегу
- Документы: чек-лист релиза, материалы для магазинов, политика конфиденциальности
### Изменено
- Урон и гибель игрока сохраняют источник (obstacle, barrel, barrel_splash, fall) для аналитики
