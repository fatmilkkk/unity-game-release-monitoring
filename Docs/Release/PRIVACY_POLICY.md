# Политика конфиденциальности игры «Шар-собиратель»

Действует с версии 1.2.0.

## Что собирается
Только **с вашего согласия** (окно при первом запуске, переключатель «Анонимная статистика» в настройках) игра записывает анонимные игровые события:
- начало и окончание сессии, длительность;
- запуск и результат уровня (победа, гибель, выход), время, собранные монеты, звёзды;
- причина и координаты места гибели на уровне;
- найденные бонусы и использованные предметы;
- средний FPS, уровень качества графики, разрешение экрана;
- технические ошибки игры (текст ошибки и место в коде);
- оценка и категория отзыва (если вы его отправили);
- модель устройства, операционная система, видеокарта, объём памяти, язык системы.

Каждой установке присваивается **случайный идентификатор**, не связанный с вами.

## Что НЕ собирается
Имя, e-mail, номер телефона, местоположение, контакты, рекламные идентификаторы, данные других приложений.

## Где хранятся данные
- Локально на вашем устройстве: папка данных приложения (`analytics/events.jsonl`, `feedback/feedback.jsonl`).
- На сервер данные отправляются только если разработчик включил сервер сбора в удалённом конфиге. В версии 1.2.0 сервер **не используется** — данные остаются на устройстве, разработчик получает их только если вы сами пришлёте файл.

## Отзывы
Отзыв из игры открывает страницу GitHub Issues в браузере. Публиковать обращение или нет — решаете вы; опубликованный текст виден всем. Техническая информация прикладывается, только если отмечен соответствующий флажок.

## Ваши права
- Отказаться от сбора в любой момент: Настройки → «Анонимная статистика» — выключить.
- При отказе все уже собранные локальные данные статистики **удаляются**.
- Удалить игру — удаляются и все её данные.

## Контакты
Вопросы по обработке данных — через GitHub Issues репозитория проекта.
