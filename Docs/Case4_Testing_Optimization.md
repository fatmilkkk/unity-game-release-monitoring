# Кейс-задача № 4. Тестирование и оптимизация игры

Проект: https://github.com/fatmilkkk/unity-game-testing-optimization

## 1. Как запустить тесты

1. Открыть проект в Unity 2022.3 LTS (сцены соберутся автоматически).
2. **Window → General → Test Runner**.
3. Вкладка **EditMode → Run All** — модульные тесты логики (`Assets/Tests/EditMode/LogicTests.cs`).
4. Вкладка **PlayMode → Run All** — интеграционные тесты механик с физикой (`Assets/Tests/PlayMode/GameplayTests.cs`).

Игровой код вынесен в отдельную сборку `PortfolioGame.asmdef`, тестовые сборки ссылаются на неё.

## 4. Найденные и исправленные ошибки

| № | Ошибка | Причина | Исправление |
|---|---|---|---|
| 1 | Прыжок, нажатый перед паузой, срабатывал после её снятия | флаг `_jumpRequested` не сбрасывался на паузе | сброс флага и сенсорного прыжка в `PlayerController.Update` на паузе |
| 2 | Уведомления могли перестать показываться навсегда | при выключении объекта корутина останавливалась, а флаг `_routine` оставался заполненным | сброс в `ToastUI.OnDisable`, перезапуск очереди в `OnEnable` |
| 3 | При выключенной перезагрузке домена (Enter Play Mode Options) статические события и пауза «переживали» перезапуск Play Mode | статические поля не сбрасывались | `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]` в Coin, BonusZone, GamePause, GameSettings, MobileInput, EffectPool |
| 4 | Вспышка света пропадала у повторно используемых эффектов взрыва | дочерний источник света уничтожался своим AutoDestroy | компонент `LightFlash` — плавное затухание с перезапуском при включении |
| 5 | Выключенный шаблон эффекта создавал выключенный экземпляр | Instantiate наследует активность | `EffectPool.Spawn` включает созданный объект |
| 6 | Кнопка «Выход» не работает в браузере и на iOS | платформа не поддерживает `Application.Quit` | `PlatformVisibility` скрывает кнопку на WebGL и iOS |
| 7 | Переключатель полноэкранного режима не имеет смысла на телефоне | — | скрыт на мобильных платформах |
| 8 | Подсказки по клавиатуре показывались при сенсорном управлении | — | `TouchControlsUI` скрывает их при включённом сенсорном вводе |

## 5. Оптимизация

| № | Что сделано | Где | Эффект |
|---|---|---|---|
| 1 | Пул объектов для эффектов частиц + прогрев при загрузке | `EffectPool`, `EffectPrewarmer`, `AutoDestroy` | нет Instantiate/Destroy и всплесков GC при сборе монет и взрывах |
| 2 | Пул значков «летящей монеты» | `CoinFlyUI` | нет создания UI-объектов на каждую монету |
| 3 | Тексты HUD пересобираются только при изменении значения | `CountersUI` | нет строковых аллокаций каждый кадр |
| 4 | Полоса HP меняет RectTransform только при изменении | `HealthUI` | Canvas не перестраивает геометрию каждый кадр |
| 5 | Кэш `GetComponentInParent` в OnCollisionStay | `MovingObstacle` | дорогой поиск не выполняется каждый шаг физики |
| 6 | Кэш `Camera.main` | `CoinFlyUI` | без поиска камеры на каждую монету |
| 7 | Монеты вне поля зрения не анимируются | `Coin` (`Renderer.isVisible`) | меньше работы в Update |
| 8 | Слои физики Player / Collectable; монеты и зоны бонусов взаимодействуют только с игроком | `PhysicsLayers`, сборщик | меньше пар для проверки в физическом движке |
| 9 | GPU Instancing для всех материалов | сборщик | одинаковые объекты рисуются меньшим числом draw calls |
| 10 | Статичная геометрия уровня (static batching) | сборщик (`isStatic`) | объединение статичных мешей |
| 11 | Монеты не отбрасывают и не принимают тени | сборщик | меньше нагрузки на проход теней |
| 12 | Дальность отрисовки камеры 500 → 150 м | `CinemachineVirtualCamera` | меньше объектов в отсечении |
| 13 | Лимит FPS (30/60/120/без), vSync под управлением настроек | `GameSettings` | экономия батареи на мобильных |
| 14 | Три уровня качества с автоматическим понижением при низком FPS | `GameSettings`, `AdaptiveQuality` | плавность на слабых устройствах |

## 6. Адаптация под устройства, экраны и ОС

- **Разрешения и соотношения сторон:** CanvasScaler (1920×1080, Match 0.5), якоря элементов по углам и краям; окна проверены по размерам для 4:3 … 21:9.
- **Смартфоны с вырезами:** `SafeAreaFitter` подгоняет HUD под `Screen.safeArea` и пересчитывает при повороте.
- **Сенсорные экраны:** виртуальный джойстик и кнопка прыжка (`VirtualJoystick`, `TouchControlsUI`, `MobileInput`), включаются по умолчанию на мобильных и сенсорных устройствах.
- **Ориентация:** только альбомная с автоповоротом (PlayerSettings).
- **ПК:** окно с изменяемым размером, полноэкранный режим Full Screen Window, разрешение по умолчанию 1920×1080.
- **Платформенные различия:** скрытие неподдерживаемых элементов (`PlatformVisibility`), качество по умолчанию «Среднее» на мобильных и «Высокое» на ПК.
- **Кроссплатформенное хранение:** все настройки и кошелёк — в PlayerPrefs (реестр Windows, plist macOS, SharedPreferences Android, IndexedDB в браузере).
